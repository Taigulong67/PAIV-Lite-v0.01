# PAIV-Lite 演示用例集

## 示例列表

### 1. Random Forest 有序分类对话
**文件**: `demo-random-forest-ordinal.json`

**场景**: 10轮对话，用户从基础概念逐步深入到具体医学应用
- 第1轮: 询问 Random Forest 基础概念
- 第2轮: 询问是否适用于有序分类
- 第3轮: 提供样本量约束（500样本）
- 第4轮: 提供具体场景约束（癌症风险、6类别、不平衡）
- 第5轮: 要求详细总结

**提取特征**:
- 语调: 友好、耐心、鼓励型
- 风格: 渐进式教学、结构化呈现、视觉化标记
- 领域: 机器学习、数据科学、医学应用

**生成 System Prompt**: `demo-random-forest-system-prompt.md`

---

### 2. PAIV 市场分析报告（战略咨询风格）
**文件**: `demo-paiv-market-analysis.json`

**场景**: 12轮深度对话，展示如何将粗略的项目概念迭代升级为专业级市场分析报告
- 第1-2轮: 分析 v2.1 版本问题，提出 v2.2 升级框架
- 第3-4轮: 确认学术风格 + 中英双语需求
- 第5-8轮: 迭代 v3.0 → v3.2，处理"只有第一页""只有提纲"等问题
- 第9-12轮: 添加真实数据引用、图表逻辑，升级至 v3.3

**提取特征**:
- 语调: 结构化升级、数据驱动、投资人视角
- 风格: 版本迭代控制、表格对比、坦诚反馈问题
- 领域: 商业战略、市场分析、融资材料、白皮书撰写

**生成 System Prompt**: `demo-paiv-market-system-prompt.md`

**关键迭代路径**:
```
v2.1 商业分析 → v2.2 战略升级 → v3.0 学术结构 → v3.1 白皮书 → v3.2 完整版 → v3.3 融资级
```

### 3. AI时代白领困境（创意写作指导）
**文件**: `demo-creative-ai-displacement.json`

**场景**: 6轮对话，展示如何通过启发式引导将社会议题转化为有情感深度的叙事
- 第1轮: 用户提出主题（AI效率 vs 白领失业），AI探索内心画面
- 第2轮: 提供3个切入角度，用户选择"微观叙事"
- 第3轮: 细化人物设定（35岁产品经理、房贷、孩子）
- 第4轮: 设计24小时时间切片结构
- 第5轮: 提供2种风格的开头片段供选择
- 第6轮: 提供3种"真实"结尾方向

**提取特征**:
- 语调: 启发式、开放式、情感共鸣
- 风格: 探索先于建议、提供选项而非标准答案、渐进式细化
- 领域: 创意写作、叙事设计、情感表达、社会观察

**生成 System Prompt**: `demo-creative-ai-displacement-system-prompt.md`

**情感弧线设计**:
```
虚假的掌控感 → 第一次震颤 → 沉默的晚餐 → 真相的凝视 → 无法入眠 → [开放式结尾]
```

## 使用方法

1. 将 JSON 文件内容复制到 PAIV-Lite 前端界面
2. 点击"转换"按钮
3. 对比生成的 System Prompt 与示例文件

## 风格对比

| 用例 | 风格 | 适用场景 | 轮次 |
|------|------|---------|------|
| Random Forest | 技术教育、渐进式引导 | 教学、技术支持 | 10 |
| PAIV市场分析 | 战略咨询、版本迭代 | 商业分析、融资材料 | 12 |
| AI白领困境 | 创意写作、情感共鸣 | 内容创作、叙事设计 | 6 |

## 添加到后端示例API

如需将此示例加入后端 `/api/examples` 返回列表，编辑 `backend/server.js` 中的 examples 数组。
